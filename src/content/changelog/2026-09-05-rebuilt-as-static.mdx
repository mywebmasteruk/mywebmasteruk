The site this replaces was built with a website builder. Every page pulled in five separate
bundles of code from four different companies before it could put anything on screen.

The replacement has none of that. Pages are prepared in advance and arrive complete, with one
small font file and nothing fetched from anybody else. This is less an optimisation than a
removal: there is no longer anything there to be slow.

The weight limit is enforced automatically whenever the site is rebuilt, so a future change that
would make it heavy fails immediately rather than quietly making the site worse over months.
